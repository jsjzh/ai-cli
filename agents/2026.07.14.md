## 需求

在 souche 下新建一个 deploy 的功能，主要用来部署当前路径的项目。

## 描述

我希望你在做之前，先把下面的接口都调用一遍，看看返回的是什么参数，返回参数声明写在 src/types/api.d.ts，然后接口写在 src/apis/index.ts 里，用 fetch 来调用

1. 先检查一下该电脑的 ~ 目录是否有 .clirc 文件，如果有的话，获取其中的 security_token_inc 值
   1. 如果没有的话，新建文件，并且声明 security_token_inc，初始化个空值
2. security_token_inc 要放在后续调用接口时的 header 里
   1. 如果有 security_token_inc，则拿着去调用下面的「获取用户信息」接口，看是否有返回正确的数据，如果 token 无效，返回的数据里 success 会是 false
3. 如果没有 token，或者获取用户信息时，返回 success 是 false，则让用户输入 token，输入后都要调用接口做校验，直到返回 sucess 是 true，再把 token 记录到 .clirc 里
4. 获取 package.json 的 name，用作「查询应用」接口的 appName，返回的可能是个列表，让用户选择
5. 选中后，拿着「查询应用」接口返回的 appId 调用「获取应用 id」接口，获得 projectId
6. 根据 projectId 调用「根据 id 获取流水线配置」，会返回多条，让用户选择
7.

## 接口

### 获取用户信息

```
curl 'https://sso.souche-inc.com/httpApi/getAuthZ.json' \
-b '_security_token_inc=91772244355866112'
```

### 查询应用

```
curl 'https://cybertron-application-api.souche-inc.com/application/list?appName=web-app-valuation-assistant&page=1&pageSize=20' \
-b '_security_token_inc=91772244355866112'
```

### 获取应用 id

```
curl 'https://wireless-devops.souche-inc.com/api/project/findProjectIdbyAppId?appId=application-b290afb2f9344f8f' \
-b '_security_token_inc=91772244355866112'
```

### 根据 id 获取流水线配置

```
curl 'https://wireless-devops.souche-inc.com/api/project/pipelines?projectId=2773' \
-b '_security_token_inc=91772244355866112'
```

### 获取 gitlabProjectId

```
curl 'https://wireless-devops.souche-inc.com/api/project/info?projectId=2773' \
-H '_security_token_inc: 91772244355866112'
```

### 获取项目分支

```
curl 'https://wireless-devops.souche-inc.com/api/gitlab/branches?gitlabProjectId=27142' \
-b '_security_token_inc=91772244355866112'
```

### 执行构建

```
curl 'https://wireless-devops.souche-inc.com/api/project/pipeline/run' \
-H 'content-type: application/json;charset=UTF-8' \
-b '_security_token_inc=91772244355866112' \
--data-raw '{"projectId":2773,"projectPipelineId":6469,"branch":"develop","commitId":"4f4adf441ccafa76e07a1c1bd05589320d1fc612"}'
```
