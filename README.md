# CLI - 命令行工具集

交互式命令行工具集，整合日常开发中的 Git 操作、SSH 配置管理、Node.js 包管理及内部工具链。

## 安装

```bash
# 使用 npm
npm link

# 或使用 pnpm
pnpm link --global
```

安装后在终端输入 `cli` 即可使用交互式菜单。

## 命令

### git - Git 操作

| 命令           | 说明                                                     |
| -------------- | -------------------------------------------------------- |
| `clone`        | 克隆仓库，可指定地址、分支、深度、文件夹名称             |
| `pull`         | 拉取当前分支最新代码                                     |
| `push`         | 先拉取远程更新，选择提交类型/范围/文件，提交并推送       |
| `pullAndMerge` | 模糊搜索分支，切换到目标分支拉取，切回原分支合并，可选推送 |
| `initAndPush`  | 在当前目录初始化 Git 仓库，添加远程，首次提交并推送      |

### gs - Git SSH 配置管理

管理多套 Git SSH 身份（如个人、工作），每套配置独立密钥对。

| 命令      | 说明                                               |
| --------- | -------------------------------------------------- |
| `add`     | 新增 SSH 配置，自动生成密钥、写入 ~/.ssh/config    |
| `list`    | 以表格形式列出所有活跃的 SSH 配置                  |
| `test`    | 测试指定 SSH 配置的连接是否正常（ssh -T）          |
| `use`     | 应用指定配置的 user.name / user.email（本地/全局） |
| `del`     | 软删除 SSH 配置（删除密钥文件，保留 gs-config 记录）|
| `current` | 查看当前 Git 身份信息，并匹配已存储的配置          |

### node - Node.js 包管理

自动识别 pnpm / yarn / npm。

| 命令      | 说明                                        |
| --------- | ------------------------------------------- |
| `install` | 自动检测包管理器并安装依赖                  |
| `update`  | 选择更新范围（全部/prod/devDeps），更新依赖 |
| `clean`   | 删除 node_modules 和 lock 文件，重新安装    |

### souche - 内部工具

| 命令   | 说明                                                         |
| ------ | ------------------------------------------------------------ |
| `sync` | 分批同步 package.json 中的依赖到内部 npm 仓库，自动切换 Node 版本 |

## 数据存储

- SSH 配置元数据：`~/.ssh/gs-config.json`
- SSH 密钥文件：`~/.ssh/`
- SSH 客户端配置：`~/.ssh/config`

## 技术栈

TypeScript + Node.js + Inquirer（交互式提示）+ Chalk（彩色输出）+ Fuse.js（模糊搜索）
